# Call Tree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A **Flow | Calls** switch in the Logic view. Calls shows a static call tree of
the Python functions, methods and classes a PR adds or changes, with their callers and
callees, built with `ast` and no Claude.

**Architecture:**
- **Backend:** a pure `calls.py` (index the worktree's Python files, resolve calls,
  pick roots from the diff, cut the neighbourhood) and `calls_api.py` (two routes and an
  in-memory cache per repo and SHA). It reuses `Checkouts`, `render` and
  `logic.function_source`.
- **Frontend:** `lib/callTree.ts` (pure filtering, focus and ELK layout), a lazy
  `CallChart.tsx`, a `CallsView.tsx` with its `CallPanel.tsx`, and the switch in
  `LogicView`. `ReviewPage` shows the Logic tab when Claude is available or the PR
  changes a `.py` file.

**Tech Stack:** Python 3.12 `ast`, FastAPI, pytest; React 19, React Query, `@xyflow/react`, `elkjs`, vitest, Playwright.

**Spec:** `docs/specs/2026-10-10-call-tree-design.md`

## Global Constraints

- Python files only. Skip `.git`, `node_modules`, `.venv`, `venv`, `__pycache__`, `build`, `dist`, `site-packages`, and files over 1 MB. At most 5,000 files (`truncated: "files"`).
- Up to 3 hops each way. At most 400 nodes; drop the farthest hops first, callees before callers at the same distance (`truncated: "nodes"`).
- Default view depth: 2 caller hops, 1 callee hop. Roots are always shown.
- Cache: the 8 most recent `(owner, repo, sha)` analyses, in memory. Concurrent requests share one computation.
- No Claude, no SQLite, nothing sent to GitHub. Works without the `claude` extra.
- `/calls/source` reads only node ids from the cached analysis, through `inside()`.
- Every route needs the access cookie and a signed-in session.
- **Rebuild after any frontend change** (`npm run build`), and commit `dist/` with the source change.
- Pin any new frontend dependency exactly. (None are expected.)
- Conventional Commits, each ending with the session's `Co-Authored-By` trailer.

## Review Focus

1. **A function changed only by deleting lines.** `render.parse_patch` reports added lines only, so a function that lost lines would look unchanged. `calls.changed_lines` also records the new-side position of every deletion, and a deletion inside a span counts as a change. Test: a patch with only `-` rows inside a function makes it a root.
2. **A package with `__init__.py` re-exports** (`from .service import save` in `pkg/__init__.py`, then `from pkg import save` elsewhere). Imports resolve through one level of re-export in `__init__.py`. Test in Task 2.
3. **Two files with the same module suffix** (`a/utils.py` and `b/utils.py`, `import utils`). No edge rather than a wrong one. Test in Task 1.
4. **A recursive function and mutual recursion.** No infinite loop in the walk, and the cycle shows. Test in Task 3 (hop distances) and Task 5 (layout doesn't throw).
5. **Switching Flow → Calls → Code view → Logic** keeps the mode, the depth settings and the open panel. Test in Task 6.

## Rulings made while planning

- **Mode lives in `ReviewPage`.** It owns `?view=` already, so it also owns `?mode=calls` and passes `mode`/`onMode` into `LogicView`. `LogicView` stays router-free for its tests.
- **Python changes** are known to the client from `page.files` (a path ending `.py`, status not `removed`). No new page flag.
- **Flow without Claude** shows "The flowchart needs Claude Code. The call tree works without it." in place of the Generate button, and doesn't call `GET …/logic`.
- **Matching a Logic function to a call node** for the Flow panel's **Calls** link: the same path, and the innermost node whose span contains the function's `start`.
- **Plan detail:** tasks list interfaces and test cases rather than full code, because the plan's author is executing it in the same session.

### Task 1: `calls.py`: index the repo

**Files:** create `src/spec_tackle/calls.py`, `tests/test_calls.py`.

**Produces:**
- `@dataclass(frozen=True) Definition`: `id: str` (`"path::Qual.name"`), `path: str`, `module: str`, `qualname: str`, `kind: "function" | "method" | "class"`, `start: int`, `end: int`, `header: tuple[int, int]`, `decorators: tuple[str, ...]`, `parent: str | None` (enclosing class id for methods, enclosing function id for nested defs), `bases: tuple[ast.expr, ...]` (classes only; excluded from eq/hash).
- `@dataclass Module`: `path`, `name`, `tree: ast.Module`, `imports: dict[str, str]` (local name → dotted target, e.g. `{"render": "spec_tackle.render", "x": "spec_tackle.render.x"}`), `defs: dict[str, Definition]` (qualname → def).
- `@dataclass Index`: `modules: dict[str, Module]` (by path), `defs: dict[str, Definition]` (by id), `skipped: list[dict]` (`{path, reason}`), `truncated: bool`; methods `find_module(dotted: str) -> Module | None` (suffix match, `None` when ambiguous or absent), `lookup(dotted: str) -> Definition | None` (module + qualname, following one level of `__init__.py` re-export).
- `module_name(path: str) -> str`.
- `build_index(root: Path, max_files=5000, max_bytes=1_000_000) -> Index`.

Nested functions get qualnames `outer.<locals>.inner`, and conditional definitions (`if`, `try`) are walked; the first definition of a qualname wins.

**Tests:**
- `module_name`: `a/b/c.py` → `a.b.c`, `a/b/__init__.py` → `a.b`.
- Definitions: functions, async functions, classes, methods (kind `method`, `parent` the class), nested functions (`outer.<locals>.inner`), spans include decorators, header spans multi-line signatures, decorators as source text.
- Imports: `import x`, `import x.y as z`, `from x import y as z`, relative `from . import y` and `from ..pkg import y`, resolved against the file's package.
- `find_module`: a `src/` layout (`spec_tackle.render` finds `src/spec_tackle/render.py`); a package `__init__.py`; two files with the same suffix → `None`.
- Skips: ignored directories, a file over the byte limit, a syntax error (in `skipped` with a reason), and the file cap (`truncated`).

- [ ] Write the tests; run `uv run pytest tests/test_calls.py -q` and see them fail.
- [ ] Implement; run until green.
- [ ] Commit `feat(calls): index Python definitions and imports`.

### Task 2: `calls.py`: resolve calls

**Files:** modify `src/spec_tackle/calls.py`, `tests/test_calls.py`.

**Consumes:** `Index`, `Definition`, `Module` from Task 1.

**Produces:**
- `@dataclass(frozen=True) Edge`: `caller: str`, `callee: str` (definition ids), `kind: "call" | "ref" | "probable"`, `lines: tuple[int, ...]`.
- `resolve_edges(index: Index) -> list[Edge]`: one edge per (caller, callee, kind), with every call-site line; a `call` edge to the same pair wins over `ref` and `probable`.

Rules (each definition's own body; nested defs and classes are visited as their own callers):
- `f` → same-module def, else `imports[f]` via `lookup`.
- `mod.f` / `pkg.mod.f` → resolve the dotted prefix through imports, then `lookup`.
- `self.f` / `cls.f` → method on the enclosing class, then its bases (repo classes, resolved like names), depth-first in order.
- `super().f` → the enclosing class's bases.
- `Class(...)` → `Class.__init__` if defined (on it or its bases), else the class.
- A function or class passed as an argument, keyword value, or assigned → `ref`.
- `obj.f(...)` unresolved → `probable` when exactly one method named `f` (non-dunder) exists in the index.
- Subclassing is a `ref` edge from the subclass to the base class, so a class node's callers include its subclasses. `isinstance(x, C)` is a reference like any other argument.
- Calls to stdlib, third-party and unresolvable names produce nothing. Self-edges are kept (recursion).

**Tests:** each rule; a star import and `getattr(obj, "f")()` give no edge; `probable` only when unique, and not for dunders; an `__init__.py` re-export; a call and a reference to the same function merge into one `call` edge with both lines.

- [ ] Tests, fail, implement, green.
- [ ] Commit `feat(calls): resolve calls between definitions`.

### Task 3: `calls.py`: roots, neighbourhood, `analyse`

**Files:** modify `src/spec_tackle/calls.py`, `tests/test_calls.py`.

**Consumes:** `build_index`, `resolve_edges`.

**Produces:**
- `changed_lines(patch: str | None) -> tuple[set[int], set[int]]`: (added lines, new-side positions where lines were deleted).
- `roots(index, changes: dict[str, tuple[set[int], set[int]]], added_files: set[str]) -> dict[str, dict]`: definition id → `{"change": "added" | "changed", "signatureChanged": bool}`.
  - Functions/methods: added when the file is new or every span line is added; changed when an added line or deletion position falls in the span (and not inside a nested def's span, which is its own root but marks its parent changed too, since nested defs show as part of the parent).
  - Classes: only lines in the span outside its methods' spans count; header = `class` line through `:` plus decorators.
  - `signatureChanged`: a changed line in the header (decorator lines count).
- `neighbourhood(edges, root_ids, up=3, down=3, max_nodes=400) -> tuple[dict[str, tuple[int, int]], tuple[int, int], bool]`: node id → `(up, down)` hop distances (a root `(0, 0)`, a non-reached direction is `None`), the depths kept, and whether it was cut.
- `analyse(root: Path, files: list[dict]) -> dict`: files are GitHub's PR files (`filename`, `status`, `patch`); returns the payload in the spec's API section (`nodes`, `edges`, `other`, `truncated`, `depth`), with `test` from the same path rule as `logicFlow.isTestPath`, and `notUpdated` on edges whose callee has `signatureChanged` and whose caller isn't a root. Nested defs are folded into their outermost function: their edges are re-pointed to it, and they aren't nodes.
- `other`: changed non-`.py` files (`"not Python"`), `.py` files with changed lines outside any definition (`"module level"`), and changed files in `skipped` (`"syntax error"`). Removed files aren't listed.

**Tests:**
- `changed_lines`: additions, a deletion-only hunk, a mix.
- Roots: an added function; a body edit; a header edit (`signatureChanged`); a decorator edit; a deletion-only edit; a class whose only change is in a method (method is a root, class isn't); a changed class attribute (class is a root); a changed base (class `signatureChanged`); a new class and its methods all roots; a nested function edit marks the outer function.
- Neighbourhood: hop distances up and down; recursion and mutual recursion terminate; `max_nodes` cuts callees before callers at the same distance and reports the depths kept.
- `analyse` end to end on a fixture repo in `tmp_path`: node fields, an unchanged caller of a signature-changed function gets `notUpdated`, a changed caller doesn't; test nodes flagged; `other` entries; a PR with no Python changes gives empty `nodes`.

- [ ] Tests, fail, implement, green.
- [ ] Commit `feat(calls): pick changed roots and cut the neighbourhood`.

### Task 4: `calls_api.py`: routes and cache

**Files:** create `src/spec_tackle/calls_api.py`, `tests/test_calls_api.py`; modify `src/spec_tackle/app.py` (include the router); `tests/conftest.py` only if a fixture is needed.

**Consumes:** `calls.analyse`, `logic.function_source`, `claude_api._signed_in`, `Checkouts.worktree`, `CheckoutError`, `CommitGone`.

**Produces:**
- `GET /api/pr/{owner}/{repo}/{number}/calls?head=` → `analyse(...)` plus `headSha`. `CommitGone` → 409 with its message; `CheckoutError` → 502 "Couldn't fetch the repository: …"; `GitHubError` → 502 "Couldn't read the PR from GitHub: …".
- `GET /api/pr/{owner}/{repo}/{number}/calls/source?head=&node=` → `function_source(root, node_ref, changed)` plus `inDiff`; 404 "No such function" for a node id not in the cached analysis (the analysis is computed first if not cached).
- `_cache: OrderedDict[tuple, asyncio.Future]` of size 8, keyed `(owner, repo, sha)`; a failed computation is evicted so a retry recomputes. The analysis runs in `asyncio.to_thread`. The cached value also keeps each node's changed lines for the source route.

**Tests** (with `web_app`, which has Claude off, and a `FakeCheckouts` whose `files` add Python sources; `FakeGitHub.files` monkeypatched per test):
- The tree comes back with nodes and edges for a changed Python function, without Claude.
- The second request for the same SHA reuses the cache (`checkouts.calls` and the analysis count once).
- Source: lines with `changed`, `inDiff`; an unknown node is 404; a node id with `../` is 404 and nothing outside the worktree is read.
- `CommitGone` → 409; `CheckoutError` → 502.
- No access cookie → 401/403 as for other routes; signed out → the same response other routes give.
- The `claude` SDK isn't imported (`"claude_agent_sdk" not in sys.modules` after a request, when it wasn't before).

- [ ] Tests, fail, implement, green. Run the whole `uv run pytest -q`.
- [ ] Commit `feat(calls): call tree routes with an in-memory cache`.

### Task 5: Frontend: types, query, `lib/callTree.ts`

**Files:** modify `frontend/src/api/types.ts`, `frontend/src/api/queries.ts`; create `frontend/src/lib/callTree.ts`, `frontend/src/lib/callTree.test.ts`.

**Produces:**
- Types `CallNode`, `CallEdge`, `CallTree` (as in the spec's payload) and `CallSource = LogicFunction without step`.
- `useCallTree(pr, head, enabled = true)` (key `["calls", owner, repo, number, head]`, `staleTime: Infinity`) and `useCallSource(pr, head, nodeId)`.
- `hasPython(files: PageFile[]): boolean`.
- `type CallFilters = { up: number; down: number; tests: boolean; probable: boolean; breakage: boolean }`.
- `visibleTree(tree: CallTree, f: CallFilters): { nodes: CallNode[]; edges: CallEdge[]; hiddenTests: Map<string, number> }`: keeps roots always; others with `up <= f.up` or `down <= f.down` (`null` meaning unreached); hides test nodes unless `f.tests`, counting hidden test callers per called node; drops `probable` edges unless `f.probable`; with `f.breakage`, only signature-changed roots and their `notUpdated` callers; drops edges with a hidden end.
- `connected(edges: CallEdge[], id: string): Set<string>`: the node, everything upstream and everything downstream of it.
- `callCardSize(node: CallNode): { width: number; height: number }`.
- `layoutCalls(nodes, edges): Promise<{ nodes: Node<{ node: CallNode; tests: number }>[]; edges: Edge[] }>` (ELK layered DOWN, edges caller → callee, ids from node ids).
- `matchCallNode(tree: CallTree, path: string, line: number): CallNode | null` (innermost span containing the line).

**Tests:** depth filtering with roots always kept; tests hidden with counts; probable toggle; breakage filter; `connected` across a cycle; `layoutCalls` returns every node and edge and doesn't throw on a cycle; `matchCallNode` picks the innermost; `hasPython`.
