# PR Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a **Map** tab to the review page. It shows a layered file-level dependency
graph of the PR (with unchanged direct importers and an indirect count) next to a
computed reading path.

**Architecture:**
- **Analysis** runs in a subprocess (`python -m spec_tackle.analysis.worker`) against a
  head checkout from `checkout.py`, with a 60 s timeout:
  - `grimp` builds the import graph
  - `ast` maps hunks to symbols and finds references
  - each file's base version is rebuilt by reverse-applying its PR patch to the head file,
    so no base checkout is needed
- **Results** are cached as JSON under `store.data_dir()/maps/`. `GET /api/pr/…/map`
  starts the job and returns `pending` until it's done.
- **Frontend:** the Map tab renders the graph with React Flow (`@xyflow/react`) and the
  reading path beside it, linked through the review store.

**Tech Stack:** Python 3.12, grimp, ast, FastAPI, pytest; React 19, @xyflow/react,
Zustand, TanStack Query, Vitest, Playwright.

**Spec:** `docs/specs/2026-10-08-pr-map-design.md`

## Global Constraints

- Phases, in order: data → core → edges → tests → other. Phase rules are applied in the
  order tests, data, edges, core, other, exactly as the spec lists them.
- Tags (first match wins): `contract`, `new`, `test`, `small` (≤ 5 changed lines), none.
- Hop 1 = unchanged modules that directly import a changed module. Hop 2+ is a count plus
  a list, never graph nodes.
- Graph limits: if there are more than 150 changed files, the graph shows the 40 largest
  hop-0 files plus their hop-1 dependents (`limits.graphTruncated`). The reading path
  always lists every file.
- grimp build timeout: 60 s. After that the map is partial (`limits.importGraph = false`)
  with path-rule ordering only.
- Cache key: `(owner, repo, base_sha, head_sha)`. A job never runs twice for one key.
- Frontend polling: every 2 s while pending.
- Reviewed state: localStorage `spec-tackle:<owner>/<repo>#<n>:map-reviewed`, a map from
  `path` to the patch hash. A file counts as reviewed only while its stored hash equals
  the current one.
- Map keys: `j`/`k` move along the reading path, `x` toggles reviewed. They're active
  only in the Map tab.

## Review Focus

1. **A repo with no Python packages** (a docs-only PR). The Map must still show the
   reading path, with a "partial" note, not an error. → Task 2 test
   `test_no_packages_is_partial`.
2. **A file whose patch GitHub omits** (too large). Its base can't be rebuilt, so it gets
   no removed or signature flags, and it still appears in the graph and path. → Task 1
   test `test_missing_patch_has_no_base`.
3. **Two Map requests at once** (two tabs). Only one job runs. → Task 3 test
   `test_concurrent_requests_share_one_job`.
4. **A head SHA change while the Map is open.** The old map stays visible with
   "Updating…" until the new one is ready. → Task 5 test `keeps the old map while
   updating`.
5. **A relative import inside a package** (`from .models import X`). It resolves to the
   right module for hop-1 references. → Task 2 test `test_relative_imports_resolve`.

```

  __init__.py
```

### Task 1: Base reconstruction and changed symbols

**Files:** create `analysis/__init__.py`, `analysis/patches.py`, `analysis/symbols.py`;
test `tests/test_analysis_symbols.py`.

**Interfaces:**
- `base_text(head_text: str, patch: str | None, status: str) -> str | None`
  - "added" → `""`
  - no patch → `None`
  - otherwise reverse-applies the unified diff hunks to `head_text`
- `@dataclass Symbol(name: str, kind: Literal["function","class","method","attribute","module"], change: Literal["added","modified","removed"], signature_changed: bool, lines: tuple[int,int])`
- `changed_symbols(base_src: str | None, head_src: str | None, added: set[int], removed: set[int]) -> list[Symbol]`.
  `added` holds head line numbers and `removed` holds base line numbers, both from the
  patch.

- [ ] Write failing tests:
  - `base_text` round-trips a patch with additions, removals and context
  - an added file gives `""`
  - `test_missing_patch_has_no_base`
  - a body edit is `modified`, not a signature change
  - a new parameter, and a new decorator, set `signature_changed`
  - a new function is `added`; a deleted one is `removed`
  - methods are named `Class.method`
  - a class-body assignment is `Class.attr`, kind `attribute`
  - an import change is one `module` symbol named `<module>`
  - `base_src=None` gives no removed symbols and no signature flags
  - a syntax error in the head source raises `SyntaxError` (the caller records `skipped`)
- [ ] Run `uv run pytest tests/test_analysis_symbols.py -q` and confirm it fails with
  `ModuleNotFoundError`.
- [ ] Implement them.
- [ ] Run the tests. They should pass.
- [ ] Commit: `feat(analysis): rebuild base files from patches and find changed symbols`

### Task 2: Import graph, hop 1, indirect, reading order

**Files:** create `analysis/graph.py`, `analysis/reading.py`, `analysis/build.py`;
modify `pyproject.toml` (`grimp`); tests `tests/test_analysis_graph.py` and
`tests/test_analysis_build.py`. A fixture builder in `tests/repo_fixture.py` writes small
packages to `tmp_path`.

**Interfaces:**
- `find_packages(root: Path) -> tuple[Path, list[str]]` returns `(import_root, names)`.
  It looks for top-level directories with `__init__.py` at the root, else under `src/`.
- `module_name(import_root: Path, path: str) -> str | None`
- `build_graph(import_root: Path, packages: list[str]) -> grimp.ImportGraph`. It adds
  `import_root` to `sys.path` while building.
- `hop1(graph, changed: set[str], import_root: Path, symbols: dict[str, list[Symbol]]) -> list[{"module", "path", "imports": [changed module], "references": [symbol names]}]`
- `indirect(graph, hop1_modules: set[str], exclude: set[str]) -> dict[str, list[str]]`
- `phase_for(path: str) -> Literal["data","core","edges","tests","other"]`
- `tag_for(file, phase, symbols) -> Literal["contract","new","test","small"] | None`
- `reading_order(files: list[{path, module|None}], graph | None) -> list[{"phase", "files": [path]}]`
- `build_map(worktree: Path, files: list[PRFile]) -> dict`. `PRFile` is
  `{path, status, additions, deletions, patch}`. The result has the spec's payload shape:
  `{status: "ready", nodes, edges, readingPath, limits, skipped}`.

  - `find_packages` at the root and under `src/`

  - `test_relative_imports_resolve`
  - indirect excludes hop 0 and hop 1
  - reading order puts dependencies first, with a cycle collapsed and the order stable
  - `test_no_packages_is_partial` (`limits.importGraph is False`, path still complete)
  - truncation over 150 files
  - a syntax-error file goes into `skipped` and is still in the reading path

### Task 3: Map jobs, cache and API

**Files:** create `analysis/worker.py`, `src/spec_tackle/maps.py`; modify `app.py`
(`/map` route, `MapJobs` on `app.state`), `github.py` (`baseRefOid` in the overview
query); test `tests/test_maps.py`.

**Interfaces:**
- `worker.py` reads `{"worktree", "files"}` JSON on stdin and prints the map JSON. It
  exits 0. An analysis failure prints `{"status": "error", "message"}`.
- `class MapJobs(root: Path, checkouts, timeout=60)`:
  - `async def get(self, *, owner, repo, base, head, files, token) -> dict` returns the
    cached map, or `{"status":"pending"}` after starting a job (once per key), or the
    stored error
  - `run_worker(worktree, files) -> dict` runs the subprocess with the timeout. On
    timeout it re-runs with `SPEC_TACKLE_NO_GRAPH=1`, giving a partial map with
    `limits.importGraph = false`.
- `GET /api/pr/{o}/{r}/{n}/map` → `MapJobs.get(...)`, plus `headSha`.

- [ ] Write failing tests:
  - pending, then ready, using a fake worker
  - a cache hit doesn't start a job
  - `test_concurrent_requests_share_one_job`
  - a worker error is stored and a later request retries it
  - timeout leads to a partial result
  - the route returns 401 when signed out
- [ ] Implement them.
- [ ] Run `uv run pytest -q`. Everything should pass.
- [ ] Commit: `feat: map jobs with cache and /map endpoint`

### Task 6: Dependency graph

tests.

**Interfaces:**
- `layoutLanes(nodes, readingPath) -> Map<id, {x, y}>` puts lanes in phase order, and

  - ▾ expands a node into its symbol list (signature changed / removed highlighted)
